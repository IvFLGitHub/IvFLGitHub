### Mi forma de trabajar

1. **Entender el problema:** observar el proceso y localizar fricciones reales.
2. **Diseñar la solución:** priorizar funciones, datos y una experiencia clara.
3. **Construir y experimentar:** usar herramientas de desarrollo e IA con criterio y revisión.
4. **Validar e iterar:** comprobar qué funciona y qué debe mejorar.
